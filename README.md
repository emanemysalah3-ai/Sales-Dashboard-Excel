## 🔍 Dashboard Contents

- **Total Sales per Territory:** compares sales across regions.
- **Shipping Methods:** share of orders by shipping method.
- **Total Sales per Month:** monthly trend across the year.
- **Top 10 Products:** best-selling products by sales.
- **Slicers:** filter by Year, Color, and Region.

## 🛠️ Tools

- Microsoft Excel (Pivot Tables, Pivot Charts, Slicers)
- Power Query (data cleaning)
